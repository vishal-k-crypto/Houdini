For web searches, minimize vision steps:

1. Open Safari (Cmd+Space, type "Safari", Enter).
2. Press **Cmd+L** to focus the address/search bar.
3. Type the search query.
4. Press **Enter** to submit.
5. Use the default search engine (Google) results.

Only use vision if the user asks you to click a specific result or interact with the page.
